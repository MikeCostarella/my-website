About this dashboard. The numbers presented here are aggregate counts derived from the Mahoning County voter registration file dated April 7, 2026. While the underlying file contains personal information for individual voters, this page deliberately presents only summary statistics — no names, addresses, birth dates, or individual records appear anywhere on this site. Voter registration data is a public record under Ohio Revised Code § 3503.13. Categories with fewer than ten people in any cross-tab have been suppressed where applicable.
